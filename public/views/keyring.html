We will launch a headless Chrome instance using Profile 24, navigate to the provider, authenticate via SSO, generate the key, and securely store it in your 1Password vault.

We will direct you to the exact page to log in and copy your API key. You will paste it here, and we will safely pipe it to 1Password and the proxy keyring.

  • Best if automation fails or is blocked by CAPTCHA
  • Works with any browser profile
